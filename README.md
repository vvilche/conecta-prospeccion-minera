# CONECTA — Prospección Minera Cobre Chile

Panel de inteligencia comercial con 11 proyectos mineros de cobre (6 brownfield + 5 greenfield).

## Qué contiene

- `index.html` — Panel interactivo: datos del proyecto, empresa de ingeniería a cargo, dirección + cargos técnicos, teléfono/correo, links a LinkedIn, y mensajes de outreach listos para copiar.
- `contactos_mineria.json` — Nombres y cargos (con URLs de fuente).
- `cargos_tecnicos.json` — Cargos técnicos (I&C, automatización, mantenimiento, proyectos).
- `ingenieria_proyectos.json` — Empresa de ingeniería (EPC/EPCM) a cargo de cada proyecto.
- `contacto_corporativo.json` — Teléfonos y correos corporativos verificados.

## Proyectos cubiertos

Brownfield: Las Cenizas, Pampa Camarones, San Gerónimo, Tres Valles, Pucobre, Altos de Punitaqui.
Greenfield: Arqueros, El Espino, Tovaku, Costa Fuego, Vizcachitas.

## Fuente

Datos recopilados vía AISA (gpt-5-search-api) con URLs de verificación. Nada inventado.
